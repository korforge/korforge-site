# korforge-site

Landing page for [Korforge](https://github.com/korforge), an open source org sharing small, focused tools.

Static HTML/CSS/JS, no build step.

## Run locally

```bash
make start            # http://localhost:8000
make start PORT=3000  # custom port
```

Requires `python3`.

## Structure

```
index.html            page content
styles.css            styles
script.js             tabs and copy buttons
assets/logos/         SVG logos (korforge, depozit, vegeta-saiyan)
```
