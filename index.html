Depozit

Slim, efficient file storage over gRPC.

Self-hosted Go server that stores and serves your files. Upload, read, list and organize files in containers from a typed Python client, sync or async.

  • Go
  • Python
  • gRPC
  • async
GitHub PyPI 
pip install depozit

# installs the Go server as a systemd user service
depozit server install

# API key is generated on first install
cat ~/.depozit/.env

depozit server uninstall   # stored files are kept
# pip install depozit
import depozit

depozit.connect("localhost:50051", api_key="your-api-key")

depozit.upload("photo.jpg", "images/photo.jpg")
data = depozit.read("images/photo.jpg")

for path in depozit.find(prefix="images/"):
    print(path)
import depozit.aio as depozit

await depozit.connect("localhost:50051", api_key="your-api-key")
data = await depozit.read("images/photo.jpg")

vegeta-saiyan

Stress test REST APIs from a JSON flow.

CLI that hits your REST endpoints with ramping load and records status, latency and errors for every request. Powered by Vegeta, bundled in one binary.

Available for Ubuntu only, for now.

  • CLI
  • load testing
  • ramp-up
GitHub Releases 
# Ubuntu only, for now
REPO=https://github.com/korforge/vegeta-saiyan
curl -Lo vegeta-saiyan $REPO/releases/latest/download/vegeta-saiyan
chmod +x vegeta-saiyan
sudo mv vegeta-saiyan /usr/local/bin/

vegeta-saiyan --help
vegeta-saiyan --flow flow.json

# results are written per request, e.g.
# results/get-on-health.json
{
  "config": { "debug": false, "remove_results_json": true },
  "profile": {
    "type": "rampup",
    "params": {
      "min_rps": 100, "min_load_duration": 3,
      "incremental_rps": 100, "incremental_seconds": 1,
      "max_rps": 1000, "max_load_duration": 3
    }
  },
  "requests": [
    { "id": "Get on health", "method": "GET", "url": "http://localhost:8000/health" }
  ]
}
